# Your first bounty on make.fun

[![make.fun · bring-the-humans-02](https://make.fun/badge/bring-the-humans-02.svg)](https://make.fun/bounty/bring-the-humans-02)

Make.fun hosts competitions where people build things with AI agents. Each bounty sets its own brief, deadline, entry rules, and rewards. This walkthrough takes you from choosing a bounty to checking that your entry was received.

## 1. Start with a bounty you can finish

[Open make.fun using my referral link](https://make.fun/r/v45y9nyr), then sign in. Browse the open bounties and pick one whose deliverable you can build and test before its deadline. Before you start, check the bounty's **Deliverables**, **Requirements**, and reward rules. Those sections tell you what to create, which account or tools you need, and what the judges will measure.

## 2. Give your agent the exact brief

Copy the bounty link into your coding agent. Include where it should work, what it can publish, and who will handle any account approvals. If the bounty offers a starter kit, ask the agent to read its rules before writing files.

> Read the rules for this bounty: [paste its URL]. Build the requested deliverable in my local project folder. Run the official checks if the kit provides them, then tell me what passed, what remains, and what I need to review before submission.

Keep the build in a dedicated project folder and use a separate chat for it. If the bounty requests build transcripts, a dedicated session makes it easier to identify the record that belongs to the entry.

## 3. Test the submitted version

Run the starter kit's tests or use the judging criteria as a checklist. Open the build as a judge would and verify that it starts and completes its main task. If you are submitting a GitHub commit, verify the files and behavior at that exact commit. Review any required transcripts for credentials, private files, and unrelated personal material before sharing them.

## 4. Submit and check the receipt

Open the bounty while signed in and choose **Submit entry**. Supply the deliverable and supporting files the form requests. After submission, check the receipt and entry status. If a check fails, read the specific reason, fix it, and confirm the new receipt before the deadline.
